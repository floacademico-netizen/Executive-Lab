# Executive Lab

Primera versión de la estructura visual de Executive Lab.

## Publicar en GitHub Pages
1. Cree un repositorio en GitHub.
2. Suba `index.html`, `style.css` y `app.js` a la raíz.
3. En Settings > Pages seleccione la rama `main` y la carpeta `/ (root)`.
4. Guarde y espere a que GitHub publique el sitio.

Esta versión contiene la estructura base para:
- Gestión
- Emprendimiento
- Destrezas
- Inglés

Los contenidos, cuestionarios, simuladores, progreso e insignias se incorporarán progresivamente.
